# Unity View Controls

Blenderの3Dビュー操作をUnity Editorに寄せるアドオン。Windows / Blender 4.4.3で検証しています。外部Pythonライブラリは不要です。

## 操作

- Alt + 左ドラッグで周回、中ドラッグで平行移動、Alt + 右ドラッグでズーム。
- 右ボタンを押している間に視点回転とWASD移動、Q/E下降・上昇。Shiftで加速、ホイールで速度調整。
- オブジェクトモードでW/E/Rの移動・回転・拡縮ツール切替、Fで選択物へフォーカス。
- アウトライナーでコレクションの三角をAlt＋クリックすると、子孫の階層までまとめて開閉します。通常クリックやBlender標準のShift＋クリックも使えます。
- コレクションを選び、右クリックメニューの「子をすべて展開／子をすべて折りたたみ」で、アクティブなコレクションの配下を一括開閉できます。複数のコレクションを選択している場合も、対象はアクティブな一つです。
- 右クリックだけなら、現在のモードのコンテキストメニューを開きます。
- 移動後に右ボタンを離すと確定。Escやウィンドウの非アクティブ化で開始時の視点へ戻します。
- 無効化で追加したキー設定と実行中の操作を解除。既存キーマップの編集・削除、作品の編集、プリファレンスの自動保存は行いません。

視点操作の主な対象はオブジェクト・メッシュ編集・ポーズモードです。W/E/RとFはオブジェクトモードだけに適用し、編集モードの押し出し・面作成などを保持します。G/Sなどの未変更のBlenderショートカットも使えます。

## インストール

1. `dist/unity_view_controls-0.1.1.zip` を用意します。
2. Blenderで「編集 → プリファレンス → エクステンションを入手」を開きます。
3. 右上のメニューの「ディスクからインストール」でZIPを指定し、有効化します。
4. 「アドオン」でUnity View Controlsを開くと、視点操作・ツール操作・コレクション一括開閉を個別に切り替えられます。移動速度・見回し感度・Shift倍率も変更できます。

コレクション一括開閉は、アウトライナーのツリー表示だけを操作します。所属、表示・非表示、ビューレイヤーからの除外は変更しません。展開状態が混在する階層のAlt＋クリックは、まずすべて展開し、もう一度で折りたたみます。

アドオンを無効化すると、追加した操作は解除されます。Blender標準キーマップ、左クリック選択、3ボタンマウスを基準としています。独自キーマップや入力系アドオンとの組み合わせは未検証です。

## Unityとの違い

- Blenderの座標系（Zが上）を維持します。Qは下降、Eは上昇です。
- UnityのQハンドツール、TのRectツール、Yの複合ツール、追従フォーカス、スナップ設定は今回の範囲外です。
- カメラビューや回転ロック中は右ボタン飛行を開始しません。カメラビューを抜けるか、回転ロックを解除してください。
- 平行投影で飛行を始めると透視投影に切り替わります。Escでは元の投影方式も復元します。
- マウス周回・平行移動・ズームはBlenderの標準処理を使います。速度や慣性までUnityと完全に一致させるものではありません。
- 飛行中のホイール速度変更は、その操作中だけ有効です。次の操作はプリファレンスの移動速度から始まります。

## 開発・確認

PowerShellで、このプロジェクトのルートから実行します。

```powershell
.\scripts\build.ps1
& 'C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe' `
  --factory-startup --enable-event-simulate --python tests/run_blender_tests.py
& 'C:\Program Files (x86)\Steam\steamapps\common\Blender\blender.exe' `
  --factory-startup --enable-event-simulate --python tests/run_outliner_tests.py
```

ビルドはBlenderの公式エクステンション検証とZIP生成を行います。テストは初期状態の別ウィンドウを使い、実際のキーディスパッチ、飛行、キャンセル、登録・解除、既存キー保持を検証します。アウトライナーテストは専用の入れ子コレクションで再帰開閉と所属・表示設定の保持を確認します。`artifacts/test-results.json` と `artifacts/outliner-results.json` に結果を出し、目視確認用にウィンドウを残します。通常の作品やユーザー設定は保存しません。
